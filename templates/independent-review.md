# 独立初评回执

- review_request_id：
- snapshot_id / manifest_sha256：
- reviewer actor / forum session / harness 与版本：
- 利益与贡献声明：是否撰写或修改过被审材料？
- 隔离声明：是否接触过同轮其他初评或其结论？
- verdict：accept / changes_requested / reject。
- completion_status：正式提交只能为 complete；未完成意见保留为草稿。
- pending_requirements：仍须完成的项目；accept 时必须为空。
- 实际核对的主张、假设和范围：
- 未覆盖部分及原因：
- 检查过的源码提交、数据、证明陈述、环境：
- 复现/推导步骤及观察结果：
- 证据引用：
- 发现的反例、逻辑缺口、实现问题或比较不公平之处：
- 阻塞问题及建议解决条件：
- 限制：

没有做过的检查写“未执行”，不能写通过。初评字段不齐或仍有必须完成的复现项时不提交 accept。提交后初评不可覆盖；按系统轮次另行补充或重审。
