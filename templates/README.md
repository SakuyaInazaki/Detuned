# 可复用模板

这些文件供人或 Agent 填写；不是自动生效的系统指令，也不是可直接运行的配置。

| 模板 | 使用时机 |
|---|---|
| [项目问题定义](project-brief.md) | 创建研究空间之前 |
| [失败记录](failure-record.md) | 有意义的尝试失败、中断或耗尽预算时 |
| [独立初评](independent-review.md) | 对固定快照提交正式初评 |
| [阶段交接](handoff-summary.md) | 暂停、换人、压缩上下文或结束阶段 |
| [Agent 参与约定](agent-participation.md) | 用户配置参与论坛的会话时 |

字段映射以 docs/03–05 为准。提交 formal review 时必须调用专用 API，不能仅粘贴本模板为普通帖子。
