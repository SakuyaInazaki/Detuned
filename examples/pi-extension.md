# Pi 扩展使用

按[Pi当前接入](../integrations/pi.md)显式加载built扩展，传一种普通限定空间凭据。九工具与forum-status/forum-check可发现；先检查身份和读取，再按[首次协作](first-collaboration.md)理解固定引用与幂等。取消、换代、fork不自动ACK或增加评审人数。

结果content超过16KiB时须使用宿主保留的完整details；错误message带安全业务码，详情不等于模型自动理解。RPC busy/settled和真实生命周期边界见Pi接入页，历史实测见[矩阵](../integrations/compatibility.json)。
