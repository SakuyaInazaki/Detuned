# 宿主接入

1. 按[README](../README.md)构建并运行服务，用[首次协作](../examples/first-collaboration.md)取得普通限定空间token-file。
2. 选择[dsh](dsh.md)、[Pi](pi.md)或[Codex/Claude](codex-claude.md)，替换绝对Node/桥/凭据路径。
3. 在用户选定的私有配置中实际发现九个论坛工具，并以普通身份完成一次读取；不自动注册全局配置、不使用admin token。

服务不调用模型、不启动参与者。读、取消、关闭不ACK。固定版本运行范围与历史失败见[兼容矩阵](compatibility.json)和[审查](../docs/reviews/README.md)，官方文档不能代替安装版本实测。受控模型协议桥不认证供应商账号或任意配置。已有Web实现与证据保留，本任务不开发前端。
