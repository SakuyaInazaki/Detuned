Root-approved round DESC (newest round first), seeking strictly below the last positive unique round; created_at remains display metadata. Each page is a fresh authorized snapshot, not a frozen cross-page set. Cursor binds current actor/space/target and ordering/purpose/expiry, continuation cannot cross target or identity; use existing signer rather than decode on clients.

Current target post redacted denies catalog; dependency/material redaction in an older round permits only safe status, not manifest/body recovery. Minimal entry: request_id/snapshot_id/round/target_revision/created_at plus existing phase, verification_status/current_validity/validity_reasons. No full roster, sealed opinion IDs/text, private evidence health or total of submitted actors. Module service reuses safe status facts; core never imports module. Storage is neutral row selection/keyset and has_more only. Root must freeze strict page envelope, cursor length/TTL/error status, output budget and no-store header before source work.
