## 其他未完成的原要求

1. **同一验证边界**：parseOperation 本轮改进，但 `extractResultRef(operation: string, result: any)` 仍使用 startsWith，未形成穷尽操作—结果映射。validator 内部仍有 any 和提前返回；运行时缺陷见 J05/J06。不要仅把函数命名为“严格”视为完成。
2. **DDL 来源**：schema.sql、schema.ts 的比较测试通过，但没有可执行的生成/读取流程；bootstrap 仍手写增量 DDL，未证明新建与升级后的列、约束、外键、索引等价。这是 R4-B.2 已指定的收口项，保持原范围，不需要通用迁移平台。
3. **固定字段与投影契约**：本轮新增 relations 历史字段，却未同步 docs/03、04、07、12。应说明不可变操作字段、当前脱敏/权限投影和 unreplayable 的条件，避免实现与规范各自推断。
4. **新基线证据**：实现目录只有 README，没有该实现后的源码指纹与逐命令原始输出。本轮独立复跑结果见 R7；不能复用旧 R6 baseline 当作 R4-B.2 实现后的证据。
5. **当前状态**：progress 顶部及 M1/B.2 行写“验收已完成”；根 README 仍停留于 R6。此次审查已更新当前入口，历史交付文本保留并注明须以新复核为准。
