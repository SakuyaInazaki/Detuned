## 共同问题与处置范围

CLI修订号parseInt静默截断是实证缺陷；缺必需参数只报通用错误、typed structured校验无路径、future expected_revision文案误导是诊断问题。CLI body与工具envelope例子易混、当前9工具被旧历史声明遮盖、工具链/PATH与警告说明不足是首用文档缺陷。

本包提供当前入口和完整[首次协作](../../../examples/first-collaboration.md)、CLI专属failure JSON、显式操作载荷对照；离线schema自发现与严格数字/安全诊断已实现并通过Arch验证。setup向导、inbox、me工具、关系目录、question关闭、自动拼页、富标题目录属于扩展，不在本包暗中新增。治理规则保持：addresses不是resolve，作者不能关闭他人challenge，provided不是验证通过，proposal不自动晋升findings。
